

# NEPTUNE
Paper：NEPTUNE: Noise-Aware Expert Tuning for Multi-Modal Knowledge Graph Completion
NEPTUNE is a framework for Multi-modal Knowledge Graph Completion (MMKGC).

## Environment

- Python 3.9

It is recommended to create a new Python 3.9 environment before running the project.

```bash
conda create -n neptune python=3.9
conda activate neptune
```

## Installation

Install all required dependencies:

```bash
pip install -r requirements.txt
```

## Running

After installing the dependencies, run:

```bash
python Neptune.py
```
